# INDEX

INDEX is a focused web-search system made up of a Next.js frontend and a separate backend API. It lets users search Google through SerpAPI using their query, location, language, and country, and view the returned results in a clean interface.

The frontend provides guest search, account registration and sign-in, and saved search history. It sends search and account requests to the backend, which handles authentication and history for signed-in users and provides search results from SerpAPI. The frontend uses the backend URL set by `NEXT_PUBLIC_API_URL` (default: `http://localhost:3080`).
